# cloud-native-lab

个人云原生实验室：在本地重建一套完整的云原生技术栈，用于恢复工程手感、
验证方案可行性，并沉淀可复用的配置与踩坑记录。

**状态：进行中** — 预计 2026 年 10 月上旬完成主体搭建

---

## 为什么做这个

离开云原生一线岗位一段时间后，我需要的不只是"复习"，而是把整条链路
重新跑通一遍——从集群、IaC、包管理、GitOps，到监控与网关。
这个仓库就是过程记录和最终产出。

## 计划覆盖的链路

| 层 | 技术 | 说明 |
|---|---|---|
| 集群 | kind / k3d | 本地多节点集群 |
| 基础设施即代码 | Terraform | 集群、命名空间、基础资源的声明式管理 |
| 应用交付 | Helm | 自研 Chart，多环境 values 管理 |
| GitOps | ArgoCD | 同步策略、漂移检测、一键回滚 |
| 可观测性 | Prometheus + Grafana | 采集配置、告警规则、SLO 燃尽率看板 |
| 网关 | Kong | 路由、插件链、限流、鉴权 |
| CI | GitHub Actions | 构建 → 测试 → 推镜像 → ArgoCD 同步 |
